Relocation Analytics Features

A spatial analytics & livability assessment tool designed to evaluate street addresses against custom transit radii and real-world amenities.

  • Street Address Geocoding: Real-time location lookup with automatic address autocomplete and spatial coordinate mapping.
  • 100-Point Match Score Engine: Custom scoring matrix comparing nearby amenities (grocery stores, cycling trails, gyms, parks, pharmacies) against personalized goals.
  • Side-by-Side Location Comparison: Compare two street addresses simultaneously to evaluate relative livability scores and amenity density.
  • Dynamic Transit Radius: Adjust transit time boundaries (2 to 30 minutes) to recalculate amenity counts instantly.
  • Cuisine Matching: Specify custom cuisine tags (e.g. Thai, Vietnamese, Indian) to evaluate dining relevance.
  • Interactive GIS Map: View surrounding POIs (Points of Interest) mapped on interactive Leaflet tile previews.
🔒
100% Private Spatial Processing All address searches, amenity scoring, and location comparisons run entirely inside your browser. No addresses or search histories are stored on external servers.
