📊 GGUF Quantization Quality Matrix

GGUF quantization balances LLM parameter size against GPU VRAM footprint:

Q8_0 / Q5_K_M — Maximum Logic & Accuracy
Near FP16 baseline quality. Best for complex coding, math, and strict instruction following. Higher VRAM footprint.
Q4_K_M — The Sweet Spot (Default)
Negligible quality loss (~0.1 perplexity drop) with ~50% VRAM reduction. Recommended for almost all setups.
Q3_K_M / IQ3 — VRAM Saver
Extreme compression to fit large parameter models (32B / 70B) onto mid-tier GPUs. Slight quality loss.
