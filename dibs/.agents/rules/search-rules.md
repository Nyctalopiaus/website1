# Search and Command Rules

Do not ask the user to manually run `git grep` commands, `Get-ChildItem` commands, `Select-String` commands, `git diff` commands, or any code search/inspection commands. Use internal tools or run search/inspection commands directly without asking the user to manually execute `git grep`, `Get-ChildItem`, `Select-String`, or `git diff`.
